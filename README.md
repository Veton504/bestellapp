# Bestell App

Lieferando-Klon für das Restaurant "Paradise Noodles".

## Starten

Die Datei `index.html` im Browser öffnen.

## Funktionen

- Gerichte in 3 Kategorien (Vorspeisen, Hauptgerichte, Getränke)
- Navigation springt zu den Abschnitten
- Warenkorb mit Menge ändern, Löschen, Lieferkosten und Gesamtsumme
- Bestellen mit Meldung
- Responsive bis 320 px
